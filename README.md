# Ilorin Lifestyle — Cloud Deployment Starter

This is a clean cloud-ready starter for Ilorin Lifestyle.

## Local test
1. Install Node.js 20+.
2. Run `npm install`
3. Run `npm start`
4. Open http://localhost:3000

## Deployment
The app listens on `process.env.PORT`, so it can be deployed to most Node.js cloud hosts.
